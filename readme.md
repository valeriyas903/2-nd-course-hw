# 2-nd-course-hw

Учебный репозиторий для домашних заданий второго курса по веб-разработке.

## О проекте

В этом репозитории собраны мини-игры и учебные задания, реализованные на HTML, CSS и JavaScript.  
Проект предназначен для практики верстки, работы с DOM, событий, адаптивной стилизации и написания интерактивных скриптов.

### Основные разделы

- **Мини-игры:**  
  - Угадай число  
  - Простая арифметика  
  - Генератор случайных цветов  
  - Простая викторина  
  - Обратный текст  
  - Камень-ножницы-бумага

- **Адаптивная верстка:**  
  Проект оптимизирован для экранов от 375px до 1440px.

- **Домашние задания:**  
  В папке содержатся JS-файлы с решениями задач по массивам, объектам, функциям и работе с DOM.
